# Дополнение курса по теории вероятностей

## Цель

Дополнить `vacuum-xvx/probability-theory` обязательными программными заданиями
с учебного плана и оригинальными тематическими ноутбуками, сохранив уже
выполненные работы без изменений.

## Итоговая структура

- `hw3/hw3.ipynb` — полная вероятность: задача о перекладывании шаров,
  классическое решение и воспроизводимое моделирование.
- `hw4/hw4.ipynb` — задачи 2.9, 2.10 и 2.11 с биномиальным распределением,
  формулой Пуассона и формулами Муавра—Лапласа.
- `topics/topic2_frequency.ipynb` — связь классической и частотной вероятности
  на примере случайного четырёхклассового классификатора.
- `topics/topic4_base_rate_paradox.ipynb` — парадокс базовых частот на примере
  детектора мошеннических транзакций.
- `topics/topic5_discrete_distributions.ipynb` — распределения Бернулли,
  биномиальное и Пуассона на примерах из систем ИИ.
- `requirements.txt` — минимальные зависимости для запуска ноутбуков.
- `README.md` — навигация по практическим и тематическим работам.

## Ограничения

- Не копировать творческие сюжеты, изображения и формулировки из референсных
  репозиториев.
- Использовать фиксированные генераторы случайных чисел, чтобы результаты
  моделирования воспроизводились.
- В каждом ноутбуке пояснять постановку, формулу, код и вывод.
- Не изменять `hw1/`, `hw2/` и `example/`.

## Проверка

- Все ноутбуки должны быть валидным `nbformat` 4.
- Все новые ноутбуки должны выполняться с нуля без ошибок через `nbclient`.
- Markdown-ссылки README должны вести на существующие файлы.
- Итоговый diff должен содержать только перечисленные новые файлы и README.
